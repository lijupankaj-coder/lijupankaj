# Verified portfolio asset checklist

All legacy portfolio images were removed from the CMS branch because their relationship to the listed projects was not sufficiently verified. Every project is seeded as a private draft with zero images. The public site therefore shows no project artwork until correct assets are uploaded and assigned.

For each project, provide 3–6 approved final visuals where available. Prefer final exports, installed-event photography and professional mockups. Recommended minimum long edge: 2000 px.

Before upload, confirm that each file:

- belongs to that exact project and year;
- is approved for public portfolio use;
- contains no internal comments, names, email addresses, budgets or client data;
- is not an editable AI, PSD, INDD or working presentation file;
- has a meaningful filename, caption and alt text;
- is not a low-resolution preview or unrelated stock/generated image.

The six approved internal applications remain text-based case studies because no public-safe screenshots were confirmed. Do not invent interface mockups. If screenshots are later approved, crop or redact all employee, client and account data before upload.
